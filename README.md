# ML Loan Approval Prediction System

An end-to-end Machine Learning web application built with Flask, Scikit-learn, and MySQL to evaluate creditworthiness and predict loan approval likelihood.

---

## 🛠️ Tech Stack & Tools
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Python (Flask)
- **Machine Learning:** Scikit-learn, Pandas, NumPy
- **Database:** MySQL

---

## 📌 Key Modules & Features
- **User Authentication:** Secure user signup and login portal.
- **Data Preprocessing & Feature Engineering:** Automated handling of demographic and financial attributes.
- **ML Model Training & Prediction:** Classification algorithms evaluated for accurate credit risk scoring.
- **Dashboard & Visualization:** Intuitive presentation of evaluation results and approval status.
